# Go2 장면 파일

이 폴더에 Unitree 공식 `unitree_mujoco`의 다음 파일을 두세요.

- `scene.xml` — 평지(및 기본 장애물) 장면
- `scene_terrain.xml` — 지형 장면
- `go2.xml`, `assets/` 등 모델 의존 파일

보통 경로는 다음과 같습니다.

```text
unitree_mujoco/unitree_robots/go2/
```

이 저장소의 제어 스크립트(`go2_korean_control.py` 등)를 `unitree_mujoco` 루트에 복사해 실행하는 것을 권장합니다.
